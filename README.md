## About Color Gradient Mesh Cloth Canvas

Color Gradient Mesh Cloth Canvas is a browser-based visual tool built with HTML Canvas. It lets you manipulate a 3x3 set of control points and observe how bilinear interpolation produces a continuously changing color surface.

The project is useful for exploring gradient mesh techniques, cloth-like deformation, and direct canvas interaction. Its controls support both desktop and touch workflows, while deformation and waving modes provide additional ways to study the rendered surface.

---

## Features

- Drag nine control points arranged on a 3x3 grid.
- Generate intermediate colors through bilinear interpolation.
- Change grid density with an adjustable slider.
- Apply randomized deformation to the mesh.
- Enable an animated waving mode.
- Interact using mouse dragging.
- Interact on touch-enabled devices.
- Visualize cloth-style movement directly in the browser.

## Usage

1. Open the HTML application in a web browser.
2. Drag any of the nine control points on the 3x3 grid.
3. Adjust the grid-density slider to change the mesh resolution.
4. Use the deformation control to introduce randomized movement.
5. Enable waving mode to view animated cloth-like motion.
6. On mobile or tablet devices, use touch dragging in place of mouse input.
